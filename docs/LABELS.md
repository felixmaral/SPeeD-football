# Labels del proyecto

Cada issue lleva **≥2 labels** (al menos tipo + prioridad) y, cuando aplica, fase y componente.

## Tipo
| Label | Uso |
|-------|-----|
| `type:feature` | Nueva funcionalidad |
| `type:bug` | Corrección de bug |
| `type:chore` | Mantenimiento / tooling |
| `type:docs` | Documentación |

## Prioridad
| Label | Uso |
|-------|-----|
| `prio:critical` | Crítica |
| `prio:high` | Alta |
| `prio:medium` | Media |
| `prio:low` | Baja |

## Fase (milestone asociado)
| Label | Milestone |
|-------|-----------|
| `phase:beta` | Beta |
| `phase:v1` | v1.0 / v1.1 |
| `phase:v2` | v2.0 |

## Componente
| Label | Área |
|-------|------|
| `comp:domain` | Dominio |
| `comp:fixtures` | Fixtures / datos |
| `comp:telegram` | Bot Telegram |
| `comp:scheduler` | Scheduler |
| `comp:leagues` | Ligas / plugins |
| `comp:config` | Config / CI / tooling |
